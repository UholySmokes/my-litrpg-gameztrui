# Voidverse Magic Physics Lore Background

## Fundamental Premise
In the Voidverse, magic is not supernatural—it's the precise manipulation of **fundamental field interactions** using structured energy inputs (mana, chi, resonance, voidspark). The universe operates under invariant physical laws: conservation, locality, causality, symmetry. Magic works *within* these laws by exploiting high-energy boundary conditions granted through **Void Covenant negotiation**.

Magic obeys physics completely. The apparent "miracles" are lawful emergent behaviors from field manipulations that baseline humanity cannot access without structured amplification.

## Core Physics-Magic Mapping

### 1. Energy Carriers (Mana & Analogues)
- **Mana**: Structured quantum vacuum fluctuation energy. Extractable via resonance with leyline field densities.
  - Physics basis: Casimir effect amplification + zero-point field tapping
  - Workable properties: Density-dependent extraction rates, coherence decay over distance
  - Limits: Ambient concentration gradients, personal resonance bandwidth
- **Chi**: Bioelectric field coherence carrier. Internal body-field synchronization.
  - Physics basis: Biofield coherence + neuromuscular synchronization
  - Workable properties: Builds through rhythmic motion, dissipates via fatigue/entropy
- **Voidspark**: Raw high-energy Void interface particles. Extremely unstable.
  - Physics basis: Planck-scale leakage from adjacent brane
  - Limits: Immediate decoherence unless field-stabilized

### 2. Field Manipulation Principles (True Physics)
Magic effects emerge from 5 canonical field interactions, each governed by exact physics:

#### Thermodynamic Fields (Heat/Phase/Entropy)
```
Core Equation: ΔS = Q_rev/T + δ_irrev (always ≥0)
```
- **Heating**: Selective molecular excitation via resonant field coupling
  - Physics: Rotational/vibrational mode targeting by frequency
  - Limit: Carnot efficiency ceiling (no free heat from nothing)
- **Phase Change**: Nucleation site forcing via pressure/temperature field gradients
  - Limit: Latent heat requirements strictly conserved
- **Entropy Export**: Required sink declaration (can't create order locally without displacing disorder)

#### Kinetic Fields (Momentum/Force/Waves)
```
F = dp/dt, ∇·F=0 (local conservation)
```
- **Force Vectors**: Momentum transfer via transient field gradient pinch
  - Physics: Impulse conservation through complete stress-energy transfer
  - Limit: No action-at-distance; recoil couples to caster/environment
- **Resonance**: Amplification via standing wave construction
  - Limit: Damping inevitable; requires continuous energy input

#### Electromagnetic Fields (Charge/Plasma/Magnetism)
```
∇×B = μ₀J + μ₀ε₀∂E/∂t
```
- **Lightning**: Dielectric breakdown path optimization
  - Physics: Paschen curve navigation for minimal resistance path
  - Limit: Skin effect, arc quenching physics
- **Plasma Control**: Magnetic confinement + thermal pinch
  - Limit: Saha ionization requiring threshold energy density

#### Gravitic Fields (Space-Time Curvature)
```
R_μν = 8πG/c⁴ T_μν (local stress-energy curvature)
```
- **Levitation**: Local metric geodesic deflection
  - Physics: Equivalent to pressure gradient in stress-energy tensor
  - Limit: Extreme energy density for meaningful curvature (Gμν requires mass-energy equivalent)
- **Time Dilation Pockets**: Transient frame-drag bubbles
  - Limit: Microscopic duration (Planck time floors)

#### Probabilistic Fields (Quantum Fluctuations)
```
P(ψ|φ) ∝ exp(-iHt/ℏ) |⟨φ|ψ⟩|²
```
- **Luck Steering**: Measurement basis selection bias
  - Physics: Observer frame influences collapse statistics (consistent with Copenhagen + decoherence)
  - Limit: Can't violate Born rule averages long-term; statistical only

## Workability (Player-Accessible Truths)

### Mana Extraction Physics
```
extraction_rate = ambient_density * personal_resonance * coherence_factor
```
- **Leylines**: High-density extraction highways (10x ambient)
- **Personal Resonance**: Trained via meditation (up to 0.8 efficiency)
- **Coherence**: Form purity reduces losses (pure = 0.95, mixed = 0.65)

### Casting Stability
```
stability = (model_fidelity * observer_lock) / field_stress
```
- **Model Fidelity**: Physics knowledge score (0.3 intuitive → 1.0 theoretical)
- **Observer Lock**: Mental focus discipline (breath cycles, stances)
- **Field Stress**: Ambient interference + scale factor

### Backlash Calculation
```
backlash = 1 - stability + (1 - model_fidelity)
```
- Effects: Temporary stat loss, technique lockout, ledger debt spike
- Sink Collapse: Local reality glitches
