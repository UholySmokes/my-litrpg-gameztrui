# Content And Worldbuild Playbook

Use this for authored content packs, archetype expansion, lore generation workflow, and worldbuilding structure.

## Default Setup

- Operator: Codex
- Model: `gpt-5.4`
- Reasoning: `high`
- Hosting: `cloud`
- Optional native companions: `.agents/skills/litrpg-war-room/`, `.agents/skills/litrpg-visual-design-studio/`

## Working Rules

1. Keep source-of-truth content in the authored data surfaces before generated outputs.
2. Preserve taxonomy consistency across systems, authorities, frameworks, overlays, and classes.
3. Validate generated or curated content with the repo’s registry and worldbuild checks.
4. Separate content design decisions from runtime implementation decisions when possible.
