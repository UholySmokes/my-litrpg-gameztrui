 ## 4. Gameplay Design Principles

The "North/South" Standard: Unless you are doing something experimental, stick to standard cardinal directions (n, s, e, w) for navigation. It reduces cognitive load.

Dynamic Descriptions: Room descriptions should change based on the state.

Example: If the player picks up the "rusty key," the room description should no longer say, "A rusty key lies on the floor."

Fail Forward: If a player fails a skill check or puzzle, try not to block progress completely. Instead, add a complication.

Example: They try to pick the lock and fail. The door opens, but the lock breaks loudly, alerting a guard.
